InsertSort

Es un método de ordenamiento de elementos, en el cual a través de la visitas de subconjuntos, un elemento es insertado en la posición ordenada que le corresponde.

Ejemplo: Insertion Sort ($\mathcal{O}(n^2)$)

Inicio:
12 11 13 5
Iteración $i=1$:
11 12 13 5
Iteración $i=2$:
11 12 13 5
Iteración $i=3$:
5 11 12 13
  • Iteración $i=1$: $\text{Key}=11$. El 11 es menor que 12. Se desplaza 12 a la derecha y se inserta 11 al inicio.
  • Iteración $i=2$: $\text{Key}=13$. El 13 es mayor que el último elemento ordenado (12). No hay desplazamientos.
  • Iteración $i=3$: $\text{Key}=5$. El 5 es menor que todos los elementos ordenados. Se desplazan los tres elementos a la derecha y se inserta 5 al inicio.

InsertSort

¿Cuál es la complejidad del siguiente algoritmo?


void insertionSort(int arr[], int n){
    int i, key, j;
    for (i = 1; i < n; i++) {
        key = arr[i];
        j = i - 1;
        
        // Mover elementos de arr[0..i-1], que son mayores que key,
        // a una posición adelante de su posición actual
        while (j >= 0 && arr[j] > key) { //esto puede ser un for
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key;
    }
}

InsertSort: Complejidad

  • Cota Superior: $\mathcal{O}(n^2)$
    (Caso peor: todo invertido).
  • Cota Inferior: $\Omega(n)$
    (Mejor caso: todo ordenado).
  • Cota Promedio: $\Theta(n^2)$
    (Caso promedio para arreglos aleatorios).

Merge Sort

Algoritmo de ordenamiento recursivo que aplica la técnica Divide & Conquer (Divide y Vencerás).

Características

  • Es Estable y rápido para grandes tamaños de datos.
  • Generalmente es superado por Quick Sort en la práctica.
  • Necesita un espacio de memoria extra para el ordenamiento ($\mathbf{\Theta(n)}$).

Ejemplo: Merge Sort

Paso 0: Inicio

3 8 2 5 1 4 7 6

Paso 1: Dividir (Nivel 1)

3 8 2 5
1 4 7 6

Paso 2: Dividir (Nivel 2 - hasta llegar a elementos unitarios)

3 8
2 5
1 4
7 6

Ordenamos

3 8
2 5
1 4
6 7
  • Fase 1 (Divide): El arreglo se divide en dos mitades. El costo de división es $\mathcal{O}(1)$.

Ejemplo: Merge Sort

Paso 3: Mezclar (Nivel 2 - Costo $\mathcal{O}(n)$ total)

3 8 2 5
1 4 6 7

Ordenar

2 3 5 8
1 4 6 7

Paso 4: Mezcla Final

1 2 3 4 5 6 7 8
  • Fase 2 (Merge): Las sublistas de tamaño 1 se mezclan para formar listas ordenadas de tamaño 2, luego 4. Este trabajo lineal se realiza en cada nivel.

MergeSort

Función mergeSort

void mergeSort(int arr[], int l, int r){ //l=izq, r=der (indices)
    if (l < r) {
        int m = l + (r - l) / 2; //div. entera

        mergeSort(arr, l, m);    // T(n/2) - dividir
        mergeSort(arr, m + 1, r); // T(n/2) - post-orden

        merge(arr, l, m, r);    // O(n) - mezclar
    }
}

Relación de Recurrencia: $\mathbf{T(n) = 2T(n/2) + \mathcal{O}(n)}$

MergeSort

Función merge (La clave de $\mathcal{O}(n)$)

void merge(int arr[], int l, int m, int r){
    int i, j, k;
    int n1 = m - l + 1;
    int n2 = r - m;

    int L[n1], R[n2]; //arreglos temporales (Costo de espacio)

    for (i = 0; i < n1; i++) 
        L[i] = arr[l + i];
    for (j = 0; j < n2; j++)
        R[j] = arr[m + 1 + j];

    i = 0; j=0; k = l; //mezcla
    while (i < n1 && j < n2) {
        if (L[i] <= R[j])
            arr[k] = L[i]; i++;
        else
            arr[k] = R[j]; j++;
        k++;
    }

    while (i < n1) //si sobra de L
        arr[k] = L[i]; i++; k++; 
    while (j < n2)  //si sobra de R
        arr[k] = R[j]; j++; k++;
}

QuickSort

Algoritmo de ordenamiento no estable de complejidad promedio $\Theta(n \log n)$. Puede en sus peores casos llegar a $\mathcal{O}(n^2)$.

QuickSort: Tres Pasos

  1. Dividir (Partition): Separa el arreglo en dos sub-arreglos alrededor de un pivote (menores y mayores que el pivote).
  2. Conquistar: Ordenar recursivamente los sub-arreglos.
  3. Combinar: trivial por condiciones iniciales.

Ejemplo: Quick Sort

Ordenar el siguiente arreglo de $n=8$ elementos: [3, 8, 2, 5, 1, 4, 7, 6]

Paso 1: Partición (Nivel 1). Pivote = 3

Ejemplo: Quick Sort

  • Fase 2 (Conquistar): El proceso de partición se repite recursivamente en los sub-arreglos [Azul] y [Naranja].
  • Fase 3 (Combinar): En Quick Sort, la combinación es trivial. Como los pivotes ya están en su lugar final, no se requiere trabajo adicional.

QuickSort (Función Principal)

Quicksort en sí es un procedimiento sencillo y recursivo.

CÓDIGO QUICKSORT 
void quickSort(int arr[], int inicio, int fin){
    if (inicio < fin) {
        
        // 1. Divide: Generar el punto de corte (j)
        int corte = partition(arr, inicio, fin);
        
        // 2. Conquistar: Llamada recursiva a la partición 
        //izquierda
        quickSort(arr, inicio, corte);
        
        // 3. Conquistar: Llamada recursiva a la partición 
        //derecha
        quickSort(arr, corte + 1, fin);
    }
}

Esquemas de Partición

Las formas más utilizadas:

  • Forma Lomuto: Pivote al final. Fácil implementación. A menudo más lento debido a intercambios redundantes.
  • Forma Hoare: Forma original. Pivote al inicio. Sofisticado. Muy eficiente (requiere menos intercambios en promedio).
  • Forma aleatoria: Pivote elegido aleatoriamente. Ayuda a evitar el peor caso en arreglos casi ordenados.

Ordenamiento por Comparación

Algoritmos como InsertSort, MergeSort o QuickSort basan su lógica en el contraste de dos valores ($\leq$ o $ >$).

Su cota inferior ($\Omega$) está limitada

  • Estos algoritmos pueden ser representados por un ABB.
  • El número de hojas debe ser al menos $n!$ (permutaciones posibles).
  • La altura min determina la complejidad: $h \ge \log_2(n!)$.
  • Como $\log_2(n!) = \Omega(n \log n)$, este es el límite inferior teórico para todo Ordenamiento por Comparación.

Ordenamiento en Tiempo Lineal ($\mathcal{O}(n)$)

Existen algoritmos que evitan la cota $\Omega(n \log n)$ porque no dependen de comparaciones.

Counting Sort

Basado en el recuento de frecuencias.

Radix Sort

Basado en el ordenamiento por dígitos.

Advertencia: Ambos tienen restricciones y su complejidad real es más fina que un simple $\mathcal{O}(n)$.

Counting Sort

Counting Sort

Se basa en contar la cantidad de ocurrencias de cada elemento.

  • Complejidad: $\mathbf{\mathcal{O}(n+k)}$, donde $n$ es el número de elementos y $k$ es el máximo valor del arreglo.
  • Uso: Ideal para enteros o representaciones discretas (claves pequeñas).
  • Restricciones: No apto para strings largos, floats o cuando $k$ es muy grande (ej. $k \gg n^2$).
  • Propiedad: Es un algoritmo estable (mantiene el orden relativo de elementos iguales).
  • Costo: memoria extra ($\mathcal{O}(n+k)$) para arreglos auxiliares.

Ejemplo: Counting Sort

Arreglo de Entrada A

2 5 3 0 2 3 0 3

Paso 1: Conteo de Frecuencias ($C[i]$)

0 1 2 3 4 5
C 2 0 2 3 0 1

Paso 2: Suma Acumulada ($C[i]$ ahora indica el índice final)

$C[i] = C[i] + C[i-1]$. Esto da el índice donde termina cada valor.

0 1 2 3 4 5
C 2 2 4 7 7 8

Ejemplo: Counting Sort

Se recorre $A$ de derecha a izquierda. Se usa $C[A[i]]$ como índice en $B$ y luego se decrementa $C[A[i]]$.

Counting Sort (Implementación Estable)


void counting_sort(int A[], int largo, int max){
    int i, ind_sgte, veces;
    int B[largo]; // Arreglo de salida
    int C[max + 1]; // Arreglo contador (de 0 a max)

    // 1. Inicializar arreglo C
    for(i = 0; i <= max; i++) 
        C[i] = 0;

    // 2. Contar ocurrencias
    for(i = 0; i < largo; i++)
        C[A[i]]++; 
    
    // 3. Calcular índices de inicio acumulados (para estabilidad)
    ind_sgte = 0;
    for(i = 0; i <= max; i++){ 
        veces = C[i];
        C[i] = ind_sgte; // C[i] ahora guarda la posición de inicio
        ind_sgte += veces;
    }

    // 4. Mover elementos a B, manteniendo el orden relativo
    for(i = 0; i < largo; i++){ 
        // B[posición_de_A[i]] = A[i]
        B[C[A[i]]] = A[i]; 
        C[A[i]]++; // Mover al siguiente índice disponible para ese valor
    }
    
    // 5. Copiar B de vuelta a A (o retornar B)
    for(i = 0; i < largo; i++){ 
        A[i] = B[i];
    }
}

Radix Sort

Algoritmo de Ordenamiento basado en dígitos. Ordena los elementos aplicando un algoritmo de ordenamiento estable (como Counting Sort) sucesivamente a cada dígito (o radix), desde la unidad menor a la mayor.

  • Complejidad: $\mathbf{\mathcal{O}(d \times (n+k))}$, donde $d$ es la cantidad de dígitos, $n$ el número de elementos y $k$ la base (usualmente $k=10$ o $k=256$).
  • Caso Común: Si $k$ es una constante (como 10), se considera $\mathbf{\mathcal{O}(d \times n)}$.
  • Pilar: Requiere que el sub-algoritmo usado para ordenar por dígito (ej. Counting Sort) sea estable.

Ejemplo: Radix Sort

PASADA 1: UNIDADES (Dígito menos significativo)

17 09 23 10 05

Resultado de Counting Sort (Ordenado por unidades):

A' 10 23 05 17 09

PASADA 2: DECENAS (Dígito más significativo)

10 23 05 17 09

Resultado Final (Ordenado por decenas de forma estable):

B 05 09 10 17 23

Radix Sort (Función Principal)


int maximo(int *A, int tam) { 
    // Función auxiliar para encontrar el elemento más grande y determinar 'd'
    int mayor = A[0];
    for (int i = 1; i < tam; i++)
        if (A[i] > mayor)
            mayor = A[i];
    return mayor;
}

void RadixSort(int *A, int tam) {
    int max = maximo(A, tam);

    // Iterar por cada 'lugar' (unidad, decena, centena, etc.)
    // 'lugar' comienza en 1 (unidades)
    for (int lugar = 1; max / lugar > 0; lugar *= 10)
        // Se asume que CountingSort se adapta para ordenar por el dígito 'lugar'
        CountingSort(A, tam, lugar); 
}

Radix Sort: Counting Sort Adaptado

El Counting Sort debe modificarse para trabajar con un dígito específico (determinado por `lugar`), no con el valor total.


void CountingSort(int *A, int tam, int lugar){ // 'lugar' = 1, 10, 100...
    int B[tam];
    int C[10] = {0}; // El contador siempre es de tamaño 10 (dígitos 0-9)

    // 1. Contar ocurrencias del dígito actual
    for (int i = 0; i < tam; i++)
        C[(A[i] / lugar) % 10]++; // Extraer el dígito en 'lugar'

    // 2. Calcular índices de inicio acumulados
    for(int i = 1; i < 10; i++)
        C[i] += C[i-1];

    // 3. Mover elementos a B desde atrás (para mantener la estabilidad)
    for(int i = tam - 1; i >= 0; i--){ 
        int digito = (A[i] / lugar) % 10;
        
        // C[digito] ahora apunta al final del segmento de ese dígito
        B[C[digito] - 1] = A[i];
        C[digito]--;
    }
    
    // 4. Copiar B de vuelta a A
    for(int i = 0; i < tam; i++)
        A[i] = B[i];
}
